# 報告書作成アプリ（配布用）

交換所の**日次報告書を作って印刷する** Android アプリの配布場所です。
ここには、スマホに入れるファイル（APK）と、使い方の手引きだけを置いています。

## アプリを入れる（はじめての人）

1. 下の **「いちばん新しい版」** をタップします。
   👉 **[いちばん新しい版を開く](https://github.com/islay2000/houkokusho-app-release/releases/latest)**
2. 開いたページを下へスクロールし、**「Assets」** の下の **「.apk」で終わるファイル**（例：`houkokusho-v1.0.63.apk`）をタップしてダウンロードします。
   「Source code」は使いません。
3. ダウンロードが終わったら **「開く」** → **「インストール」** をタップします。
   「この提供元のアプリを許可」と聞かれたら、スイッチをオンにして戻ります（最初の1回だけ）。

くわしい手順は、使い方の手引きの「2　アプリを入れる・新しくする」を見てください。

## 新しい版にする（2回目から）

アプリの **1.0.63 から**は、アプリを開いたときに新しい版があると **「新しい版があります」** と出ます。
**「更新する」** → **「インストール」** をタップするだけです。

- 更新しても、**日報・設定・入れていた数字は消えません。**
- **アプリを消さないでください。** 消すと、中の日報もすべて消えます。

## 困ったとき

- 「新しい版を確かめられませんでした」と出たときは、スマホがネットにつながっているか確かめてください。
- そのほかは、手引きの「7　困ったとき」を見てください。
